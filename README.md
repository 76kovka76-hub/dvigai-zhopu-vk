# «Двигай жопой, блядь!» — автопубликация VK

Скрипт публикует короткие безопасные упражнения без тренажёров и специальной подготовки в сообщество VK **10 раз в день**.

## Расписание

Время московское (UTC+3): 08:00, 09:30, 11:00, 12:30, 14:00, 15:30, 17:00, 18:30, 20:00 и 21:30.

GitHub Actions запускает расписание в UTC. Фактический старт может немного задерживаться из-за очереди GitHub Actions.

## Один раз добавить секреты

Откройте репозиторий → **Settings → Secrets and variables → Actions → New repository secret**.

Добавьте:

- \`VK_ACCESS_TOKEN\` — токен сообщества VK с разрешением на публикацию записей на стене.
- \`VK_GROUP_ID\` — ID сообщества: \`74712378\`.

Токен не нужно отправлять в переписку или записывать в файлы репозитория.

## Проверка

После добавления секретов откройте **Actions → VK exercise auto-publisher**. Ручной запуск через **Run workflow** сразу создаёт одну настоящую публикацию в VK. Не запускайте его, если не хотите тестовый пост.

Дальше публикации будут выходить автоматически по расписанию.

## Защита от повторов

История опубликованных текстов хранится в \`post_history.json\`. Перед публикацией скрипт проверяет историю и не отправляет повторный текст или повторный слот за день. Если история повреждена или закончились уникальные варианты, скрипт останавливается, не публикуя запись.

Каждая запись содержит одно короткое задание и ровно три разных хэштега.
